# GPS-Based Attendance System

A web-based attendance management system developed using Laravel as part of a Diploma 3 (D3) final project. The application uses GPS location tracking to support employee attendance recording and provides features for attendance history and reporting.

## Project Overview

The GPS-Based Attendance System was developed to support employee attendance management through a web application integrated with location-based verification. It allows employees to record attendance, review their attendance history, and access attendance reports through an authenticated system.

This project demonstrates the implementation of web development, database management, and GPS-based functionality in an attendance management solution.

## Key Features

- **GPS-Based Attendance** — Uses location data to support attendance verification.
- **Authentication** — Provides a login system for authorized users.
- **Attendance History** — Allows employees to review their attendance records.
- **Attendance Reports** — Supports access to attendance reporting.

## Technologies Used

- Laravel
- PHP
- MySQL
- HTML, CSS, and JavaScript
- GPS / Geolocation

## Project Purpose

This project was developed as a final academic project for the Diploma 3 (D3) program. It applies software development and database management concepts to build a practical attendance management system with location-based functionality.
